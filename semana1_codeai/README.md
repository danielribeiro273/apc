# Relatório das Atividades - Semana 01 (Code AI)

Durante esta primeira semana nas atividades do curso de Code AI (Laboratório de Jogos / Game Lab), realizei os exercícios correspondentes às lições de criação de sprites, alinhamento de textos e formatação de ecrã. A minha maior dificuldade foi alinhar o tamanho dos textos e ajustar as coordenadas e eixos x/y dos elementos na tela. Consegui resolver testando posições no ambiente de desenvolvimento e verificando a ordem de renderização no código, alcançando os resultados esperados em todas as avaliações e desafios do Code AI.
